## REA 사용 내역

- 이 작업 환경과 연결된 Windows PC(book-e5hvbr0qrf)의 작업 환경 모두, 대상 사이트(hq-tech.co.kr, krackerz.com) 접속이 네트워크 정책(프록시 403)으로 막혀 REA가 번들을 직접 받지 못했습니다. PC에서 npm 접속은 가능했습니다.
- 대신 REA의 정적 분석 방식(라우트·데이터 출처 추적)을 Chrome 안에서 현행 번들(`/assets/index-*.js`, 561KB)에 적용해 라우트 14개와 사례·뉴스가 `/api/*`에서 오는 구조, 그리고 그 API의 500 오류를 확인했습니다.
- 맥미니 터미널에서 직접 돌리려면: `npx -y rea-agents@latest analyze-web-bundle https://www.hq-tech.co.kr/news --json`
